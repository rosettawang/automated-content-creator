Spec run log

A long run outlives its own context — the conversation gets summarized while the run is still going. This file is where each spec's outcome is written as it finishes, so the end-of-run report is generated from disk, not from a faded memory. Append here; never batch at the end.

What each entry records

What shipped · how it was verified (the command, the test, what you exercised — not the word "verified") · what was deviated from and why · what is left. Write it for someone who was not here.
